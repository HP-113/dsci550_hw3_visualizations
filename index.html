Haunted Places Data Exploration - Spring 2025

Explore Visualizations

Description

This project visualizes haunted place reports across the U.S. using multiple perspectives. Each visualization helps uncover hidden patterns — including time of day, apparition types, and geographic clustering.

Insight

Through this exploration, we can observe recurring apparition trends, regional clustering, and correlations with external factors such as time, location, or type of reported phenomena.
